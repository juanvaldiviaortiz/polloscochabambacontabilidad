Documentación Técnica de la API - Pollos Cochabamba

1. Introducción

Nombre de la API: Pollos Cochabamba API

Objetivo: Gestionar empleados, capital, marketing y movimientos financieros de la empresa.

Descripción: Sistema desarrollado en Flask con base de datos MariaDB, que permite administrar recursos humanos y financieros.

Funcionalidades principales:

  • Registro e inicio de sesión de usuarios.
  • Gestión de empleados.
  • Gestión de capital y marketing.
  • Control de movimientos financieros.

2. Acceso y autenticación

Método: API Key

La API requiere enviar la API Key en el header x-api-key de cada solicitud.

Ejemplo de solicitud autenticada:

GET http://127.0.0.1:5000/empleados
Headers:
x-api-key: mi_api_key_segura

3. Rutas o Endpoints

/login

  • Método: POST
  • Descripción: Inicia sesión con email y contraseña.
  • Body: { "email": "user@mail.com", "password": "1234" }
  • Respuesta: { "message": "Login exitoso" }

/registro

  • Método: POST
  • Descripción: Registra un nuevo usuario.
  • Body: { "nombre": "Juan", "email": "juan@mail.com", "password": "1234", "rol": "admin" }
  • Respuesta: { "message": "Usuario registrado correctamente" }

/empleados

  • Método: GET / POST
  • Descripción: Listar o registrar empleados.
  • Headers: x-api-key
  • Respuesta GET: [ { "id": 1, "nombre": "Pedro" } ]

/capital

  • Método: GET / POST
  • Descripción: Consultar y ajustar capital.
  • Headers: x-api-key
  • Respuesta GET: { "total_general": 100000, "fondo_nomina": 10000 }

4. Formato de datos

La API utiliza JSON para enviar y recibir información.

  • Headers: x-api-key
  • Body: JSON
  • Respuesta: JSON

5. Dirección y acceso a los datos

Flujo: Cliente → API Flask → MariaDB → Respuesta JSON

El cliente envía datos en JSON, la API los procesa y consulta/actualiza la base de datos, devolviendo una respuesta en JSON.

6. Diccionario de datos

CampoTipoObligatorioDescripciónEjemplo
idIntegerSíIdentificador del registro25
nombreStringSíNombre del empleado"Juan"

7. Ejemplos de consumo

Postman

GET http://127.0.0.1:5000/empleados
Headers:
x-api-key: mi_api_key_segura

cURL

curl -X GET http://127.0.0.1:5000/empleados \
-H "x-api-key: mi_api_key_segura"

Python (requests)

import requests

headers = {"x-api-key": "mi_api_key_segura"}
r = requests.get("http://127.0.0.1:5000/empleados", headers=headers)
print(r.json())

8. Manejo de errores

La API devuelve errores en formato JSON:

{
  "statusCode": 401,
  "message": "API Key inválida"
}
  • 401: Autenticación fallida.
  • 404: Recurso no encontrado.
  • 500: Error interno del servidor.
